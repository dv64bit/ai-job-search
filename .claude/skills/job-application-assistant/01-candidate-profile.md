- **Moody's credit rating platform (design lead, rolling out):** Designed a single platform replacing a scattered MS Word + email process, covering the full credit-rating report lifecycle in three connected pieces: (1) a design-system layer where users define primitives (fonts, colors, links, token values) and combine them into reusable blocks; (2) a content-designer side assembling blocks into report templates and report management; (3) an authoring micro-application where authors write the report, reviewers comment and approve, and the report is published to the Moody's website. Design team was first point of contact for client stakeholders; produced screens, user flows, IA, and site maps that development built from. Targeted at 2,000+ users; still rolling out, no measured outcomes.
- **Marvell Technology P2P Hub (design + coded front-end):** Procure-to-pay hub consolidating request tracking previously split across Oracle EBS, Beeline, and Conga. Designed the full application and user flow from client requirements, then built the ~25-screen front-end (React 18 + TypeScript + Tailwind) as a working application so stakeholders could walk the real flow; handed the codebase to developers for backend integration.
- **InfraWatch - AWS cost optimization dashboard (scope, IA, design system, UI, coded prototype):** Cut a 20-capability multi-cloud BRD down to a 5-capability MVP scoped around one verifiable loop (connect AWS, understand spend, find opportunities, understand why); documented tradeoffs as a decision record. Designed a 3-step onboarding + 9 dashboard screens, with insufficient-data, empty, loading, and error states as first-class screens. Built the "Space Org Console" design system: 191 tokens, dark/light/print themes from one token set, hue reserved for meaning (blue interactive, green healthy, orange attention, red critical), plus an audit script that fails the build on raw hex, off-scale type, and gradients. Coded the prototype (React 19, TypeScript, Vite, Tailwind v4, react-router, ~16k lines) including a custom animated charting layer without a charting library. Prototype complete, nothing measured.
- **CogniVault - knowledge intelligence platform (internal, end-to-end owner, design phase complete):** Re-scoped from project-phase management into a company-wide knowledge repository after stakeholder review; cut 5 personas to 3 + a config surface and collapsed a 14-tab project detail view into a compliance-first structure. Defined per-persona user flows (PM, Leadership, Engineer, Admin) as the shared design/engineering spec. Redesigned the Leadership dashboard from an aggregate stat wall into a per-project Portfolio Command Center. Ran 4 rounds of usability revision on the live prototype (phase-scoped compliance checklists). Designed a 7-phase compliance scoring model across 16 document types. Built its design system and a design-audit script enforcing token use in code; prototype in React + TypeScript + Tailwind. Not built into production.
- **Cognida Design System (founder / owner):** Company's first design system. Defined the design language and tokens, then assembled a component library from vetted open-source primitives (multiple libraries) restyled to the org's language. Covers charts, avatars, badges, breadcrumbs, buttons, checkbox groups, dropdowns, inputs, tables, modals, navbars, tooltips, icons, grid/spacing foundations, design annotations. Web applications only. Adopted across active product teams.
